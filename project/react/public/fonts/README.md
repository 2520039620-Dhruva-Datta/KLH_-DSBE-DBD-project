# Self-hosted font sources

Unmodified variable TrueType fonts from the Google Fonts repository, downloaded 10 September 2026:

- Lora: https://github.com/google/fonts/tree/main/ofl/lora — `Lora-Variable.ttf`, `Lora-OFL.txt`.
- Source Sans 3: https://github.com/google/fonts/tree/main/ofl/sourcesans3 — `SourceSans3-Variable.ttf`, `SourceSans3-OFL.txt`.

Both are distributed under SIL Open Font License 1.1. The accompanying license and copyright notices must remain with redistribution. The application serves these locally; it does not request Google Fonts at runtime.
